## Special Topics

A collection of nice (or sometimes advanced) topics which I find particularly interesting.

### Model Assessment

- Conformal prediction (& other prediction intervals)
- Metrics
- Model comparison
- Troubles with benchmarks
- Double descent in bias-variance tradeoff

### Problem Types

- Ordinal regression
- Multioutput classification & regression
- Stochastic physical systems

### History and Culture

- Two cultures (statistics vs machine learning, frequentist vs Bayesian)
- The rise of deep learning
- Limits of Large-Language Models
- Modelling with and without human inductive biases
- Trends in computational hardware (analog vs digital, GPUs & TPUS, neuromorphic hardware)

### Neuroscience

- Learning in the brain (perceptual coding, active inference, and other theories)
- Biologically plausible architectures (spiking neural networks, symbolic learning architectures, sleepy architectures)
